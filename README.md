# DÜNYA SEN HAREKET EDİNCE VAR

> *"Sen durursan zaman ve evren de donar."*

Özgün 2D atmosferik web oyunu. Oyuncu hareket etmedikçe dünya var olmaz; her adım yeni zeminleri, kadim monolitleri, kristalleri ve gizemli patikaları gerçek zamanlı olarak doğurur.

## 🎮 Oynanış
- **Yön Tuşları (↑ ↓ ← →)** veya **WASD** ile hareket et.
- Sen adım attıkça baktığın yöne doğru evren inşa edilir.
- Bir süre durup beklersen evrenin sana fısıldadığı mesajları gör.
- 6 bölümün ardındaki hakikati keşfet.

## 🛠️ Teknolojiler
- HTML5 Canvas API
- Web Audio API (Procedural Synthesizer - harici ses dosyası gerektirmez)
- CSS3 Glassmorphism & Neon Glow
- Vanilla JavaScript
